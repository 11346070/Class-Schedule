# 個人課表維護系統

Django 期中專題，提供學生查課、選課、退選、收藏、查看每週課表及畢業學分進度等功能。

## 系統功能

### 1. 帳號管理
- 支援註冊、登入及登出確認。
- 個人設定可修改姓名、學號、班級、密碼及頭貼。
- 學號為 5～12 碼英數，學生填寫後不可自行修改；管理員可更正。
- 頭貼支援 JPG、JPEG、PNG、WEBP，最大 2MB。
- 班級選項由後台管理，已被使用的班級不可刪除。
- 尚未填妥個人資料時，首頁會提醒，但不影響選課。
- 儲存班級後，該班級及全校必修會自動加入課表。必修不可自行退選；若與一般選課衝堂，會優先保留必修。
- 導覽列可切換深色／淺色模式，設定保存在瀏覽器。

### 2. 課程清單與收藏
- 可依課程名稱、教師、編號、類型、星期及剩餘名額篩選，每頁 10 筆。
- 支援選課、退選、收藏及查看課程詳情。
- 課程名稱下方顯示作業量與考試難度的最多人評價結果。
- 課程詳情顯示所屬模組、選課限制及課程大綱。
- 課程大綱提供檢視與下載，未上傳時顯示「尚未上傳」。
- 無法選課的原因會顯示於課程詳情或收藏清單的操作提示。

### 3. 個人課表
- 首頁顯示週一至週日、第 1～13 節及各節上課時間，第 10 節不顯示時間。
- 顯示已選學分、學分上限、退選下限及已選門數。
- 學分進度條標示下限位置，並提供學分上下限相關提醒。
- 超過學分上限仍可選課，但超出部分不一定能認列。
- 支援匯出 PDF、PNG，匯出內容為目前登入者的課表。

### 4. 選課規則
- 防止重複選課、衝堂、名額已滿及超過資訊／金融模組學分上限。
- 超過個人學分上限仍可選課，超出部分需自行確認是否能認列。
- 預檢不會占用名額；正式選課會透過交易及課程鎖定更新名額，並建立「正在修」紀錄。
- 退選後若低於個人或模組學分下限，學生不可自行退選，需由管理員處理。
- 管理員調降學分上限時，已選課程會保留，前台僅顯示提醒。
- 不認列的課程由管理員於歷年修課紀錄標記。

### 5. 修課進度
- 依畢業總學分、必修、選修及通識門檻顯示已取得與尚缺學分。
- 已取得學分只計算歷年「已通過」，「已過但不認列」不計入。
- 本學期正在修的學分獨立計算。
- 可選擇主修模組，查看已通過、正在修及模組學分上下限。
- 資訊與金融模組之間，另一模組的已通過學分最多認列至上限。
- 歷年修課紀錄可依學期及狀態篩選，管理員修改狀態後會同步更新。
- 學生退選僅會刪除「正在修」紀錄。

### 6. 課程評價
- 正在修課或已有該課修課紀錄的學生可填寫或更新評價。
- 評價項目包含作業量（多、適中、少）及考試難度（難、適中、易）。
- 每位學生每門課限一則評價。

### 7. 後台管理
- 使用 Django Admin 與 SimpleUI 管理學生、課程、班級、選課、收藏、課程評價、畢業門檻、模組學分限制及歷年修課紀錄。
- 授課教師、教室、開課班級可直接於課程表單旁新增。
- 班級、教師及教室可修改名稱，已被使用時不可刪除；修改後相關課程會同步顯示新名稱。
- 教師若在同一時段有其他課程，儲存時會提示，但課程仍可保留。
- 教室可留空，課表、課程清單及匯出皆會顯示教室。
- 支援設定多個上課時段及不同教室，選課衝堂與教師時段檢查會涵蓋所有時段。
- 課程可指定學期，後台可修改學期代碼、名稱及目前學期；同一時間僅有一個目前學期。
- 學生課表及選課清單只顯示目前學期，舊學期課程可查看詳情但不可選課。
- 學生資料包含學號、班級、主修模組及頭貼。
- 儲存班級或必修課程時會自動加入對應必修；若與一般選課衝堂，會優先保留必修。
- 必修彼此衝堂時會全部保留並於課表並排顯示。
- 管理員可刪除學生選課紀錄，但不可退選的必修下次開啟課表時會重新加入。
- 課程大綱限 PDF，最大 10MB。
- 後台加選使用相同選課規則；後台退選不受學分下限限制，並同步更新名額。
- 歷年修課紀錄支援單筆修改及批次設定狀態。

## 技術架構

- **後端：** Python、Django 6（6.0 以上、6.2 以下）
- **資料庫：** SQLite、Django ORM，登入狀態存於資料庫
- **前端：** Django Templates、原生 CSS、JavaScript
- **後台介面：** django-simpleui
- **其他：** CSRF 防護、Django 密碼驗證、選課交易與列鎖定、上傳檔案內容檢查

## 本機安裝與執行

### 1. Clone 專案

```bash
git clone https://github.com/11346070/Class-Schedule.git
cd Class-Schedule
```

### 2. 建立虛擬環境並安裝依賴

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 套用資料庫

專案已附上寫好展示資料的 `db.sqlite3`。下載後執行 migrate 只會補上尚未套用的結構，不會清掉課程、帳號與選課紀錄。

```bash
copy .env.example .env
python manage.py migrate
```

沒有 `.env` 也能啟動。設定檔已有本機用的預設值。

### 4. 啟動系統

```bash
python manage.py runserver 127.0.0.1:8000
```

展示帳號如下，兩組密碼相同。

| 用途 | 帳號 | 密碼 | 登入後 |
| --- | --- | --- | --- |
| 學生前台 | `demo` | `ClassDemo2026` | 已有課表、收藏、評價與歷年成績 |
| 管理後台 | `admin` | `ClassDemo2026` | http://127.0.0.1:8000/admin/ |

若展示資料被改亂，可還原成同一套結果：

```bash
python manage.py seed_demo
```

## 系統網址

- **前台：** http://127.0.0.1:8000
- **後台：** http://127.0.0.1:8000/admin/

## 注意事項

- 本專案以本機執行為主，供課堂展示與測試使用。
- `db.sqlite3` 與 `media/syllabi/`（展示用課程大綱）納入版本控制，下載後不用再自行建課或註冊。`.env`、`.venv/` 與 `media/avatars/`（頭貼）不納入。
- 資料庫是 SQLite 單一檔案，可以直接放上 GitHub。展示庫遠小於 GitHub 的 100MB 限制；登入狀態存在同一份資料庫，不依賴本機的 sessions 資料夾。密碼雜湊已寫在資料庫裡，與 `.env` 的 SECRET_KEY 無關。
- 這份資料庫給課堂展示使用，帳號與密碼寫在上面。請不要放真實個資。
- 首次執行且資料庫無課程時，系統會載入示範課程，並補上資訊、金融模組的示範課。要連帳號與選課結果一起還原，請改執行 `python manage.py seed_demo`。
- 新帳號預設學分上限為 25、退選下限為 9。
- 畢業門檻預設總學分 128（必修 60、選修 40、通識 28），模組認列上限為 9。
- 模組學分上下限預設為 0，表示不額外限制。以上設定皆可由後台調整，前台重新整理後即會更新。

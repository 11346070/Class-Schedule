# 個人課表維護系統

Django 期中專題，提供課程查詢、選課、退選、個人課表與修課進度。

## 系統功能

1. **課程清單與搜尋**
   - 可用關鍵字、課程類型、星期篩選，並看到名額與不能選的原因。
   - 可選課、退選、收藏，以及查看課程詳情和評價。課程清單與收藏清單使用同一套表格，不另外顯示狀態欄，表格在頁面寬度內換行。
   - 多頁時顯示筆數、頁碼與目前頁。課程名稱下的作業量、考試難度，是把每一則評價分開統計，各取人數最多的那一項。
   - 課程詳情會顯示所屬模組。可以選的課不再另外跳出提示。若已上傳課程大綱，可另開分頁檢視或下載 PDF；尚未上傳時不會出現空白連結。

2. **個人課表**
   - 每週課表同時顯示節次與上課時間，可匯出 PDF、PNG。
   - 顯示已選學分、學分上限與退選下限。

3. **選課規則**
   - 檢查重複選課、衝堂、名額、個人學分上下限，以及資訊、金融模組的學分上下限。
   - 選課前預檢不會占用名額。低於退選下限時，只能由管理員退選。

4. **修課進度**
   - 已取得只算歷年已通過的學分，本學期正在修的課另計。
   - 這一頁的「正在修」來自本學期選課。後台歷年修課紀錄是另外登錄的成績；課程或帳號不同時，兩邊狀態不會相同。
   - 管理員把同一門課改為已通過後，這一頁的狀態與已取得學分會跟著更新，不會再把該課算成正在修。
   - 可在此選擇主修模組；另一模組學分依認列上限互認。
   - 模組學分上下限由管理員設定，這一頁會顯示目前數值。

5. **個人設定**
   - 修改密碼與上傳頭貼，兩個區塊同高，登出在左側區塊下方。
   - 頭貼接受 JPG、JPEG、PNG、WEBP，檔案最大 2MB。

6. **後台管理**
   - 用 Django Admin 管理學生帳號、課程、選課、收藏、課程評價、畢業門檻、模組學分限制與使用者學分上下限。
   - 學生模組只保留主修模組與頭貼。學分上下限提醒固定開啟。
   - 可上傳或更新課程大綱 PDF，並在修課紀錄列表直接修改狀態，或批次標為已通過、未通過、正在修。

## 技術架構

- **後端：** Python 3.12、Django 6.x
- **資料庫：** SQLite、Django ORM
- **前端：** Django Templates、原生 CSS、JavaScript
- **其他：** Session、CSRF 防護、資料驗證與交易控制

## 本機安裝與執行

### 1. Clone 專案

```bash
git clone https://github.com/11346070/Class-Schedule.git
cd Class-Schedule
```

### 2. 建立虛擬環境並安裝依賴

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 設定環境變數並建立資料庫

```bash
copy .env.example .env
python manage.py migrate
```

### 4. 建立管理員帳號並啟動系統

```bash
python manage.py createsuperuser
python manage.py runserver 127.0.0.1:8000
```

## 系統網址

- **前台：** http://127.0.0.1:8000
- **後台：** http://127.0.0.1:8000/admin/

## 注意事項

- 本專案以本機執行為主，供課堂展示與測試使用。
- `db.sqlite3`、`.env`、`.venv/` 與 `media/`（頭貼、課程大綱）不納入版本控制。
- 首次執行資料庫遷移後，若資料庫尚無課程，系統會自動載入示範課程。
- 學分上下限、畢業門檻與模組學分限制都在後台調整，前台重新整理後即會更新。

# 個人課表維護系統

Django 期中專題。學生可查課、選課、退選、收藏，並查看每週課表與畢業學分進度。

## 系統功能

1. **帳號**
   - 註冊後直接登入。登出前會再確認一次。
   - 個人設定可改密碼、上傳頭貼。頭貼接受 JPG、JPEG、PNG、WEBP，最大 2MB，只會改到自己的帳號。
   - 導覽列可切換深色／淺色，選擇記在這台瀏覽器。

2. **課程清單與收藏**
   - 可用關鍵字（名稱、教師、編號）、課程類型、星期篩選，也可只看尚有名額。每頁 10 筆。
   - 清單顯示剩餘名額，可選課、退選、收藏、看詳情。課程名稱下會附作業量與考試難度（各取評價人數最多的一項）。
   - 不能選的原因顯示在課程詳情。可以選的課不另外顯示提示。收藏清單裡，不能選的按鈕滑過可看到原因。
   - 課程詳情顯示所屬模組。有上傳大綱才會出現檢視、下載；沒有檔案時顯示「尚未上傳」。

3. **個人課表**
   - 首頁顯示週一到週日、第 1–13 節與上課時間（第 10 節沒有對應時間），以及已選課程卡片。
   - 同時顯示已選學分、學分上限、退選下限、已選門數。學分條會標出下限位置。
   - 已達或接近退選下限、已達或超過學分上限時，首頁會顯示提醒。這是固定規則，設定頁不能關閉。
   - 可匯出 PDF 或 PNG。檔案在瀏覽器產生，內容是目前登入者的課表。

4. **選課規則**
   - 擋下重複選課、衝堂、名額已滿、超過個人學分上限，以及超過資訊或金融模組學分上限。
   - 畫面上的預檢不會占用名額。正式選課在同一筆交易裡鎖定課程並更新名額，同時寫入一筆「正在修」。
   - 退選後若會低於個人學分下限，或低於該模組學分下限，學生不能自行退選，需由管理員處理。
   - 管理員之後把上限調低時，已選的課會保留，只在首頁和修課進度顯示提醒。

5. **修課進度**
   - 已取得只算歷年「已通過」。本學期正在修的學分另計，不計入已取得。
   - 依畢業總學分，以及必修、選修、通識門檻，顯示已取得與還差多少。
   - 可選擇主修模組（資訊或金融）。另一模組已通過的學分，最多認列到上限，超出部分不計。
   - 歷年修課紀錄可依學期、狀態篩選。管理員把狀態改成已通過後，這一頁會跟著更新。學生退選只會刪掉「正在修」的那一筆。

6. **課程評價**
   - 正在修，或已有該課修課紀錄的人，可在課程詳情填寫或更新。
   - 作業量為多、適中、少；考試難度為難、適中、易。每人每課一則。

7. **後台管理**
   - 使用 Django Admin 與 SimpleUI，管理學生帳號、課程、選課、收藏、課程評價、畢業門檻、模組學分限制、使用者學分上下限、學生模組與歷年修課紀錄。
   - 學生模組只保留主修模組與頭貼。
   - 可上傳課程大綱，須為 PDF，最大 10MB。
   - 後台加選走同一套選課規則。後台退選不受學分下限限制，並會同步名額。
   - 歷年修課紀錄可直接改狀態，或批次標為已通過、未通過、正在修。

## 技術架構

- **後端：** Python、Django 6（`6.0` 以上、`6.2` 以下）
- **資料庫：** SQLite、Django ORM。登入狀態存在資料庫，不使用 session 檔案。
- **前端：** Django Templates、原生 CSS、JavaScript
- **後台介面：** django-simpleui
- **其他：** CSRF 防護、Django 密碼驗證、選課交易與列鎖定、上傳檔案的內容檢查

## 本機安裝與執行

### 1. Clone 專案

```bash
git clone https://github.com/11346070/Class-Schedule.git
cd Class-Schedule
```

### 2. 建立虛擬環境並安裝依賴

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 設定環境變數並建立資料庫

```bash
copy .env.example .env
python manage.py migrate
```

### 4. 建立管理員帳號並啟動系統

```bash
python manage.py createsuperuser
python manage.py runserver 127.0.0.1:8000
```

## 系統網址

- **前台：** http://127.0.0.1:8000
- **後台：** http://127.0.0.1:8000/admin/

## 注意事項

- 本專案以本機執行為主，供課堂展示與測試使用。
- `db.sqlite3`、`.env`、`.venv/` 與 `media/`（頭貼、課程大綱）不納入版本控制。
- 首次執行後若資料庫尚無課程，系統會載入示範課程，並補上資訊、金融模組的示範課。
- 新帳號的學分上限預設 25、退選下限預設 9。畢業門檻預設總學分 128（必修 60、選修 40、通識 28），模組認列上限預設 9。模組學分上下限預設 0，表示不額外限制。這些都在後台調整，前台重新整理後即會更新。

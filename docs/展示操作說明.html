1. 課表總覽（約 2 分鐘）

  1. 以 demo 登入，進入首頁。
  2. 看本週課表：已選 10 門、22 學分，上限 25、退選下限 20。狀態會顯示「接近退選下限」。
  3. 週一「程式設計(一)」與「程式設計實驗」並排，下方提醒兩門必修時間重疊、學生不能自行退選。
  4. 「計算機概論」出現兩個時段：週三第 6–8 節（資訊館 201）與週一第 11–12 節（資訊館 電腦教室）。
  5. 按「匯出課表」，可匯出目前這位學生的 PDF 或 PNG。

2. 選課規則（約 2 分鐘）

到「課程清單」。課程名稱下方有最多人的作業量與考試難度，例如「程式設計(一)」是作業多、考試適中。可用關鍵字、類型、星期與「僅顯示尚有名額」篩選。

3. 收藏、大綱與評價（約 2 分鐘）

  1. 打開「收藏清單」。已收藏上面四種情況：金融市場可選，其餘三門按鈕是停用的。點「詳情」會看到不能選的原因。
  2. 打開「程式設計(一)」或「人工智慧」，課程大綱可檢視、下載 PDF。打開「環境科學」則顯示「尚未上傳」。
  3. 「人工智慧」下方已有這位學生的評價，按鈕是「更新評價」。清單上的文字是大家投票後最多的結果。
  4. 回到首頁，對「人工智慧」按退選。系統會拒絕：退完剩 19 學分，低於下限 20，必須請管理員處理。必修課程的按鈕則是「不可退選」。

4. 修課進度（約 2 分鐘）

  1. 打開「修課進度」。已取得 34／128。必修 16（正在修 12）、選修 8（正在修 8）、通識 10（正在修 2）。正在修與未通過都不計入已取得。
  2. 主修資訊會顯示已通過 3、正在修 6、下限 3、上限 6，並註明不認列 3 學分。這 3 學分是「網頁前端」，在歷年紀錄把狀態選成「已過但不認列」就能看到。選「未通過」則會看到普通物理。

5. 後台（約 2 分鐘）

  1. 登出後以 admin 進入後台。
  2. 課表管理 → 歷年修課紀錄，搜尋「陳同學」。勾選「環境科學」，動作選「標為已通過」。回到前台重新整理，通識已取得會從 10 變成 12。
  3. 課表管理 → 課程，打開「程式設計(一)」按儲存。會出現警告：王教授在同一時段還有「程式設計實驗」。課程仍會保留。
  4. 學生資料裡可看到學號、班級與主修模組。學號學生自己不能改，管理員可以更正。

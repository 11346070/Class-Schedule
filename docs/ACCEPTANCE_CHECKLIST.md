# 手動驗收清單

## 驗收目的
確保個人課表維護系統的所有核心功能正常運作，符合專題需求與預期結果。

## 驗收環境

- **作業系統：** Windows 10/11
- **Python 版本：** 3.12 或以上
- **瀏覽器：** Chrome、Edge、Firefox（任一）
- **網址：** http://127.0.0.1:8000

## 驗收前準備

1. ✅ 確認虛擬環境已建立並啟動
2. ✅ 確認依賴已安裝（`pip install -r requirements.txt`）
3. ✅ 確認 .env 檔案已建立
4. ✅ 執行系統檢查（`python manage.py check`）
5. ✅ 啟動開發伺服器（`python manage.py runserver 127.0.0.1:8000`）
6. ✅ 在瀏覽器開啟 http://127.0.0.1:8000

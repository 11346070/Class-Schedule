  • Session 管理：檔案式 Session
  • 模板引擎：Django Templates

系統說明

資料儲存方式

本系統使用 SQLite 資料庫儲存課程、選課與收藏資料，伺服器重啟後資料仍會保留。

實作說明

  • 首次啟動且資料庫無課程時，會自動載入示範課程
  • 選課／退選使用交易與鎖定，避免名額並發問題
  • 使用者仍以 Django Session 識別

選課規則

  • 不能重複選擇同一門課程
  • 不能選擇已額滿的課程
  • 不能選擇時間衝突的課程（同一天、節次重疊）
  • 退選後名額會立即釋放

使用者識別

系統使用 Django Session 識別不同使用者，每個瀏覽器 Session 視為一位獨立使用者。

核心功能

  • ✓ 課程清單瀏覽與搜尋
  • ✓ 課程詳細資訊查看
  • ✓ 個人課表維護（選課、退選）
  • ✓ 課程時間衝突檢查
  • ✓ 課程名額管理與占用
  • ✓ 每週課表視覺化
  • ✓ 學分統計
  • ✓ 響應式設計

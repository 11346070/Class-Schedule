技術架構

  • 後端框架：Django 6.1
  • 程式語言：Python 3.12
  • 資料儲存：記憶體儲存（無資料庫）
  • Session 管理：檔案式 Session
  • 模板引擎：Django Templates

系統說明

資料儲存方式

本系統不使用任何資料庫（SQLite、MySQL、PostgreSQL），所有課程資料及選課資料均儲存於 Python 記憶體中。

重要限制

  • 伺服器重新啟動後，所有選課資料會重置為初始狀態
  • 多個 Worker 或多個伺服器程序無法自動共用記憶體資料
  • 本專題採用單一 Django 程序執行，確保名額管理正確
  • 使用 threading.Lock 機制防止並發選課問題

選課規則

  • 不能重複選擇同一門課程
  • 不能選擇已額滿的課程
  • 不能選擇時間衝突的課程（同一天、節次重疊）
  • 退選後名額會立即釋放

使用者識別

系統使用 Django Session 識別不同使用者，每個瀏覽器 Session 視為一位獨立使用者。

核心功能

  • ✓ 課程清單瀏覽與搜尋
  • ✓ 課程詳細資訊查看
  • ✓ 個人課表維護（選課、退選）
  • ✓ 課程時間衝突檢查
  • ✓ 課程名額管理與占用
  • ✓ 每週課表視覺化
  • ✓ 學分統計
  • ✓ 響應式設計
